# ccmw — Claude Code Multi-Window

터미널에서 Claude Code를 멀티 탭으로 실행하고, 파일 브라우저·Git 패널·AI 코드 리뷰를 한 화면에서 사용할 수 있는 TUI 도구입니다.

[Textual](https://github.com/Textualize/textual) 기반으로 작성되었으며 `claude` CLI가 설치된 환경에서 동작합니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| **멀티 터미널** | Claude 세션과 Shell을 탭으로 나란히 실행 |
| **파일 브라우저** | 디렉터리 탐색 및 Git 상태 인라인 표시 |
| **파일 뷰어** | 선택한 파일을 구문 강조와 함께 즉시 확인 |
| **Git 변경사항** | 변경 파일 목록, 스테이지/언스테이지, 커밋 |
| **Diff 뷰어** | Unified / Split 두 가지 모드 지원 |
| **원격 동기화** | Pull · Push, 원격 ahead/behind 커밋 수 표시, upstream 자동 설정 |
| **브랜치 관리** | 로컬·원격 브랜치 목록, 체크아웃, 생성, 삭제 |
| **git init** | 저장소가 없는 디렉터리에서 즉시 초기화 |
| **Git 히스토리** | 커밋 목록 조회, Soft/Mixed/Hard 리셋, Revert, AI 커밋 리뷰 |
| **AI 코드 리뷰** | 변경 diff 또는 특정 커밋을 Claude에게 전달해 리뷰 리포트 생성 |
| **이미지 뷰어** | 파일 브라우저에서 선택한 이미지를 터미널 하프블록 문자로 미리보기 |
| **세션 관리** | 기존 Claude 세션 목록 조회 및 재개 |
| **클립보드 이미지 붙여넣기** | `Ctrl+V`로 클립보드 이미지를 PNG 파일로 저장해 경로를 터미널에 붙여넣기 (macOS) |
| **입력 언어 표시** | 현재 IME 언어(한/EN)를 상태바에 표시 |

## 설치

Python 3.11 이상 및 [Claude Code CLI](https://github.com/anthropics/claude-code) 설치가 필요합니다.

```bash
# uv 사용 (권장)
uv pip install .

# 또는 pip
pip install .
```

```bash

ccmw

ccmw --cwd /path/to/project
```

## 키 바인딩

### 전역

| 키 | 동작 |
|----|------|
| `q` | 종료 |
| `Tab` / `Shift+Tab` | 패널 포커스 이동 |
| `Ctrl+N` | 새 탭 열기 (Claude / Shell 선택) |
| `Ctrl+W` | 활성 탭 닫기 |
| `h` | 숨김 파일 토글 |
| `e` | 파일 뷰어 토글 |
| `s` | 세션 목록 열기/닫기 |
| `r` | 파일 브라우저 새로고침 |
| `g` | Git 패널 열기/닫기 |

### Git 패널 — 변경사항 뷰

| 키 / 버튼 | 동작 |
|-----------|------|
| `r` | 상태 새로고침 |
| `Space` | 선택 파일 스테이지/언스테이지 |
| `a` | 모든 파일 스테이지 |
| `d` | Diff 모드 전환 (Unified ↔ Split) |
| `p` · **↓ Pull** 버튼 | `git pull` |
| `u` · **↑ Push** 버튼 | `git push` (upstream 없으면 자동으로 `--set-upstream origin <branch>`) |
| `v` · **✦ AI 리뷰** 버튼 | 전체 변경 diff를 Claude에 전달해 리뷰 리포트 생성 |
| `x` | 선택 파일 변경 되돌리기 |
| `b` | 브랜치 뷰로 전환 |
| `h` | 히스토리 뷰로 전환 |
| `i` · **⊕ git init** 버튼 | `git init` — 저장소가 없을 때만 표시 |
| `ESC` | 패널 닫기 |

### Git 패널 — 히스토리 뷰 (`h` 키로 전환)

| 키 / 버튼 | 동작 |
|-----------|------|
| **Soft** 버튼 | 선택 커밋으로 `git reset --soft` (스테이지 유지) |
| **Mixed** 버튼 | 선택 커밋으로 `git reset --mixed` (스테이지 해제) |
| **Hard!** 버튼 | 선택 커밋으로 `git reset --hard` (변경사항 삭제, 확인 필요) |
| **Revert** 버튼 | 선택 커밋을 `git revert` (새 커밋으로 되돌리기) |
| **✦ AI 리뷰** 버튼 | 선택 커밋의 diff를 Claude에 전달해 리뷰 리포트 생성 |
| `h` · `ESC` | 변경사항 뷰로 돌아가기 |

### Git 패널 — 브랜치 뷰 (`b` 키로 전환)

| 키 / 버튼 | 동작 |
|-----------|------|
| `Enter` · **체크아웃** 버튼 | 선택한 브랜치로 전환 (원격 브랜치는 로컬 추적 브랜치 자동 생성) |
| `n` | 새 브랜치 이름 입력창 포커스 |
| `Enter` (입력창) · **생성** 버튼 | `git checkout -b <name>` (생성 후 즉시 전환) |
| `Ctrl+D` · **삭제** 버튼 | 선택한 로컬 브랜치 삭제 (`git branch -d`, 안전 삭제) |
| `r` | 브랜치 목록 새로고침 |
| `b` · `ESC` | 변경사항 뷰로 돌아가기 |

### AI 리뷰 모달

| 키 | 동작 |
|----|------|
| `c` | 리뷰 내용 클립보드 복사 |
| `Enter` | 추가 질문 전송 |
| `ESC` | 닫기 |

## Git 패널 상세

### 원격 상태 표시

타이틀 바에 로컬과 원격의 커밋 차이를 실시간으로 표시합니다.

```
git  변경 3  스테이징됨 1  ⇡2 ⇣1
```

| 표시 | 의미 |
|------|------|
| `⇡N` | 로컬이 원격보다 N커밋 앞섬 → Push 필요 |
| `⇣N` | 원격이 로컬보다 N커밋 앞섬 → Pull 필요 |

### 브랜치 목록 표시

```
* main          ← 현재 브랜치 (녹색)
  feat/foo      ← 로컬 브랜치
  fix/bar
  origin/main   ← 원격 브랜치 (흐리게)
  origin/dev
```

### git init

Git 저장소가 없는 디렉터리에서 패널을 열면 **⊕ git init** 버튼과 안내 메시지가 표시됩니다. 실행 후 패널이 즉시 갱신됩니다.
